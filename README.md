# 🌦️ Weather App

A simple and responsive Weather App built using Python and Flask.

The application allows users to search for a city and view current weather information and a 5-day weather forecast.

## 🚀 Features

- 🔎 Search weather by city name
- 🌡️ Current temperature
- 💧 Humidity
- 💨 Wind speed
- ☀️ Weather condition
- 📅 5-day forecast
- 🌤️ Dynamic weather background
- 🌧️ Rain background
- ⛈️ Thunderstorm background
- ☁️ Cloudy background
- 🌫️ Fog background
- ❄️ Snow background
- 📱 Responsive design
- ⚠️ Error handling for invalid cities and API problems

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- REST API
- Open-Meteo Weather API
